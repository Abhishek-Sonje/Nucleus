nucleus v1.0

Privacy Policy

Last updated: May 2026

TL;DR — Nucleus collects nothing. Zero data ever leaves your browser. There are no servers, no accounts, no analytics, no tracking of any kind.

What data Nucleus accesses

Nucleus reads AI chat conversations from the active browser tab when you explicitly click "Capture Chat" or press the keyboard shortcut. It reads only the message content visible on the page.

How data is stored

All captured data is stored exclusively in chrome.storage.local — a sandboxed storage area inside your browser that is:

  • Only accessible to the Nucleus extension itself
  • Never synced to Google servers or any cloud service
  • Never shared with any third party
  • Deleted permanently when you uninstall the extension

Data transmission

Nucleus makes no network requests to any server, API, or external service. The only optional network call is fetching a selector configuration JSON from a CDN to keep platform scrapers up to date. This request contains no user data whatsoever — only the extension version is sent as a standard browser User-Agent header.

Permissions explained

  • storage — to save captured pills to local browser storage
  • activeTab — to read the current tab's URL to detect which AI platform you're on
  • scripting — to inject the content script into AI chat tabs so messages can be read
  • host permissions (claude.ai, chatgpt.com, gemini.google.com) — required for the content script to run on those pages

No permission is used beyond its stated purpose above.

Third parties

Nucleus does not integrate with, send data to, or receive data from any third party. There are no analytics SDKs, no crash reporters, no ad networks.

Children's privacy

Nucleus does not collect any personal information from anyone, including children. The extension has no accounts, sign-ups, or data collection of any kind.

Changes to this policy

If this policy changes, the updated version will be published at this URL with a new "Last updated" date. Continued use of the extension after a policy update constitutes acceptance of the updated policy.

Questions? Open an issue on GitHub or contact the developer directly via the Chrome Web Store listing page.
